# Smoke-тест Master Presets

Короткий ручной чеклист. Прогонять после правок в `javascript/`, `scripts/` или `style.css`.
Изменённое содержимое существующих файлов подхватывается жёстким обновлением страницы (Ctrl+F5);
новый файл в `javascript/` появляется только после Settings → Actions → «Reload custom script
bodies (No ui updates, No restart)» плюс Ctrl+F5. Проверяется в живом Forge на `127.0.0.1:7860`.

## Панель и инициализация
- [ ] Панель «Master Presets» видна вверху txt2img и img2img; кнопки пресетов и размеры отрисованы
- [ ] Live preview показывает `W×H · пропорция · MP` и морфит рамку при смене размера

## Быстрые размеры
- [ ] Клик по сохранённому размеру меняет Width/Height; кнопка `16:9` меняет пропорцию, сохраняя площадь
- [ ] `↔ Orientation` меняет W/H местами; `W ↔ H` (link): изменение Width пересчитывает Height по пропорции
- [ ] `×64` округляет автогенерации к 64; `0.5x` / `2.0x` масштабируют текущий размер

## Применение пресетов (Svelte-дропдауны — хрупкая зона)
- [ ] Переход anima→zit: тост «Пресет применен» без предупреждения; UI Preset, checkpoint, Steps, CFG, Distilled CFG, Sampler встали по пресету
- [ ] Переход zit→anima: checkpoint и модули (VAE / Text Encoders) восстановлены; промпты подставились
- [ ] Hover по чужому пресету — оранжевые чипы «было → станет»; по выбранному при совпадении — полные настройки; после ручной смены UI Preset в Forge — снова диф
- [ ] Кнопка `Preset size W×H` применяет размер выбранного пресета

## Управление пресетами
- [ ] `Save preset` сохраняет тестовый пресет; красная корзина в Edit buttons удаляет его с подтверждением
- [ ] `Export` скачивает JSON (с порядком пресетов/форматов и именами форматов); `Import` принимает его обратно и восстанавливает раскладку

## Режим правки и перетаскивание
- [ ] «Правка кнопок»: перетаскивание пресета/размера/формата вправо ставит элемент ПОСЛЕ цели, влево — ПЕРЕД; порядок живёт после F5
- [ ] Сброс мимо кнопок не теряет перенос: соскользнувший с кнопки сброс использует последнюю кнопку того же типа под курсором; сброс в чистый промежуток (когда под курсором кнопки не было) ставит элемент после последнего элемента своего ряда
- [ ] Клик в режиме правки НЕ применяет пресет/размер/формат; красная корзина удаляет (для пресетов требуется подтверждение); вне режима правки клики работают как раньше
- [ ] Сид/хайрез: пересохранённый пресет показывает чипы «Сид» и «Хайрез фикс»; пресет, сохранённый до их появления, эти поля не трогает

## UI расширения
- [ ] ▴/▾ сворачивает и разворачивает панель; после F5 сворачиваемость сохраняется
- [ ] Свёрнутый бар: первые 3 пресета и 3 формата кликабельны, hover-карточки работают
- [ ] `Save as format`: создание именованного формата, дифф, удаление 🗑 в режиме правки (встроенные пропорции не удаляются); тултипы на месте; кастомный формат живёт после F5
- [ ] Кнопка `?` открывает справку

## Правила безопасности при прогоне
- Не удалять пользовательские пресеты (Anima, Zit и производные) — только тестовый.
- В конце прогона вернуть размер 1024×1024.
